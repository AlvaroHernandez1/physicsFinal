# physicsFinal

We are recreating a problem on conservation of angular momentum from the first semester. In said simulation, two skaters on frictionless ice move along opposite parallel paths, when they hit and grap onto a rod and rotate. 

We will be allowing the user to control the skaters respective masses and intial velocities, as well as the pole which will have significant angular inertia. The user can also pick where the skaters collide with the pole. We are also considering adding friction to slow the system to a stop.
